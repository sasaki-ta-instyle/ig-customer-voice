# 顧客ボイス

ペルソナに声で質問すると、選んだものと理由を顧客の言葉で答え、ずんだもんの声で読み上げます。

## 起動

```bash
cd ig-customer-voice && ./start.sh
```

VOICEVOX が起動していなければ立ち上げ、サーバを起動して Chrome で `http://localhost:4780/` を開きます。止めるときはターミナルで Ctrl+C。

VOICEVOX が入っていないメンバーは、チーム版 `https://mb.instyle.group/ig-customer-voice/` を Chrome で開きます（共通パスワードはチーム内で共有）。読み上げは無く文字だけですが、マイクでの質問・多数決・パネルは同じように使えます。チーム版で作ったペルソナはチーム全員に見えるので、クライアントの実名や未公開の数字は書かないでください。

## 使い方

1. 左でペルソナを選ぶ
2. マイクボタンを押して話す（話し終えると自動で送信）。文字入力して Enter でもよい
3. 「選んだもの」「セリフ（読み上げ）」「マーケ目線の理由（根拠タグ付き）」が出る
4. 続けて「じゃあ 8,000 円なら？」のように聞くと、前の会話を踏まえて答える
5. 口調は左の切替か、会話で「ずんだもんで話して」「普通に戻して」と頼む

ペルソナを変えると会話はリセットされます（別のお客さんなので）。

## メビウスの顧客（既定）

一覧の先頭は「メビウス製薬」の 4 人です。起動するとその 1 人目が選ばれ、「パネルで聞く」も 4 人そろって始まります。

- **SIMIUS 新規** — 広告や LP で初めて知り、買うかどうか考えている人
- **SIMIUS 既存定期**（「主力」マーク）— 定期で使い続けていて、今の売上を支えている人
- **TRIPURE** / **UPTIS** — 各ブランドの顧客

答えには「前向き／条件しだい／後ろ向き」の札が付きます。主力顧客が後ろ向きなら「クリティカル」、条件しだいなら「要注意」と出ます。新商品や施策が新規には刺さっても、既存定期のお客さんを離れさせるなら、そこを先に判断してください。

この 4 人はローカルの自分用（`_outputs/customer-panel/personas/` の `mb-*.md`）が正本です。購買データや定期の解約理由が分かったら、そこに書き足してください。チーム版へは `scripts/sync-personas.sh` で配ります（チーム版では読むだけ）。

## 化粧品ニュース朝報を根拠にする

シロコが毎朝流している「化粧品ニュース朝報」の直近 3 か月分から、質問に近い記事を自動で数件選んで、答えの材料にしています。マーケ目線の理由に「朝報 11/11 FASHIONSNAP」のような青い札が付いたら、他社の動きと比べた判断です。札を押すと元の記事が開きます。答えの下には、根拠にした記事の一覧が出ます。

- お客さんの声（セリフ）で「最近〜を見た」と言うのは、その人が普段見る一般向けの媒体の記事だけです
- 朝報は 1 日 5 件ほどの抜粋です。記事が無いことは「他社がやっていない」という意味ではありません

## 精度について

- 既定で同じ質問を 5 回聞いて多数決にしています（左の「5 回聞いて多数決」）。答えの上に「5 回中 4 回：プラセンタ」と出ます。6 割以下なら「割れています」＝その人にとって決め手が弱い質問です
- 理由のタグがオレンジ枠なら、AI が補った「（仮）」の項目に乗った判断です。データで確かめていません
- いちばん効くのは、ペルソナを作るときに「事実」欄へ購買データやインタビューを貼ることです。一覧の「仮 n / 13 項目」が少ないほど、実際の顧客に近いペルソナです
- 1 人に聞いた答えは 1 人の反応です。市場の割合を見たいときは「パネルで聞く」を使います

## パネルで聞く

1. 左の「パネルで聞く」を押す（いま選んでいる人と同じ領域の人がまとめて選ばれる）。タップで 2〜8 人に入れ替える
2. 分かっていれば、各人に「構成比」を入れる（例：購入者データで 50〜60 代が 7 割なら、その年代の人に 70）。全員分入れると市場の割合として集計、空なら 1 人 1 票
3. 質問すると、全員に 5 回ずつ聞いて「ヒアルロン酸 67%（2 人）」のように分布が出る。下に 1 人ずつの答え・理由・声
4. 「じゃあ 8,000 円なら？」のような続きの質問も、人ごとに前の答えを踏まえて答える

1 回の質問で Claude を 10〜40 回呼ぶので、待ち時間は 15〜30 秒です。注意書き（設計ペルソナ／（仮）が多い／構成比なし）が出ている間は、割合を市場の数字としては扱わないでください

## ペルソナの管理

購買データやインタビューで分かった事実を書き込むほど、設計上の人物像から実際の顧客に近づきます

- 一覧にカーソルを乗せると、属性・前提・購買行動・口調の全文が出ます
- ペルソナは「30〜40 代女性」のような集団ではなく 1 人。集団の説明を書いても下書きは 1 人に絞られ、年齢が幅や「〜代」のままだと保存できません
- 「＋ 追加」→ 領域・性別・年齢・段階をタップで選ぶ（どれも任意）→ 必要なら「ひとこと」を書くかマイクで話す → 「作る」（15〜20 秒）→ プレビューを見て「保存して話す」で、そのまま質問できる
- AI が補った「（仮）」の行は薄い色で出ます。気になれば「作り直す」、細かく直すなら「Markdown で直す」を開く
- 自分用（「自分用」マーク付き）は鉛筆で編集、ゴミ箱で削除（`_trash/` に移すだけなので戻せます）
- customer-panel 同梱の共有ペルソナはチーム配布物なので、ここでは編集・削除できません
